# 오더허브 (OrderHub)

스마트스토어 · 쿠팡 · 11번가 · G마켓 · 옥션 · 롯데ON 주문을 **API로 자동 수집**하고, 새 주문이 들어오면 **휴대폰으로 바로 알려주는** 판매자용 웹앱입니다.
주문자·수취인 정보를 보고 직접 발주를 넣은 뒤, 공급처에서 받은 **송장번호를 입력하면 마켓에 발송처리까지** 한 번에 끝납니다.

```
[스마트스토어] ─┐
[쿠팡 Wing]  ──┤                         ┌─▶ 📱 웹앱 푸시 (홈 화면 앱)
[11번가]    ──┼─▶ 오더허브 서버 (5분마다) ─┼─▶ 📱 텔레그램
[G마켓·옥션] ──┤    주문 저장·발주·송장     └─▶ 📱 ntfy
[롯데ON]    ──┘
                         ▲
                 휴대폰/PC 브라우저로 접속
```

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 주문 자동 수집 | 5분마다(1~120분 설정 가능) 모든 스토어의 신규주문을 가져옵니다 |
| 휴대폰 알림 | 신규주문 · 취소/반품/교환 요청 · 배송지 변경 · 수집 오류를 알림. 알림을 누르면 해당 주문이 바로 열립니다 |
| 주문 상세 | 받는 분 이름·연락처·우편번호·주소·배송메모·**개인통관고유부호**를 항목별 복사 / **발주정보 전체복사** |
| 발주 관리 | [발주완료] 처리 + 공급처·공급처 주문번호·매입가·메모 기록, 마진 자동 계산 |
| 마켓 발주확인 | 발주완료 시 마켓에도 발주확인(상품준비중) 자동 처리 (설정에서 변경) |
| 송장 입력·발송처리 | 택배사 + 송장번호 입력 → 마켓에 송장 등록(발송처리)까지 자동 |
| 송장 일괄등록 | 엑셀에서 `주문번호 · 택배사 · 송장번호`를 복사해 붙여넣기 → 한 번에 발송처리 |
| 엑셀(CSV) 다운로드 | 발주서로 쓸 수 있도록 주문·수취인·상품 정보를 내려받기 |
| 상태 탭 | 신규주문 / 발주완료 / 발송완료 / 배송완료 / 취소·반품 / 전체, 검색(이름·전화·주문번호·상품명) |
| 취소 감지 | 발주한 주문이 취소되면 "공급처 주문도 취소하세요" 긴급 알림 |
| 고객 문의 | 스마트스토어 고객문의·상품문의 수집 + 알림 + **오더허브에서 바로 답변**, 쿠팡 상품문의 수집·알림(베타, 답변은 Wing) |
| 베타 연동 진단 | 11번가·G마켓·옥션·롯데ON은 [연결 테스트]에서 마켓 응답 구조를 보여줘 문제를 빨리 찾을 수 있습니다 |
| 보안 | 관리자 비밀번호 로그인, API 키는 서버에 암호화 저장, 주문 정보는 내 서버에만 보관 |

지원 마켓: **네이버 스마트스토어**(커머스API), **쿠팡**(Wing Open API), **11번가**(Open API, 베타), **G마켓·옥션**(ESM Trading API, 베타), **롯데ON**(OpenAPI, 베타), 데모 스토어(체험용)

## 왜 "서버"가 필요한가요?

스마트스토어·쿠팡·11번가·G마켓·옥션·롯데ON API는 모두 **미리 등록한 고정 IP에서 온 요청만** 받아줍니다.
그래서 휴대폰 앱이나 무료 웹호스팅(IP가 계속 바뀜)으로는 연동할 수 없고, **IP가 고정된 서버 1대**에서 오더허브를 24시간 켜두어야 합니다.
샵모아 같은 유료 서비스도 같은 방식(업체 서버 IP를 마켓에 등록)으로 동작합니다.

| 방법 | 비용 | 특징 |
| --- | --- | --- |
| **AWS 라이트세일 (가장 쉬움)** | 요금제에 따라 월 몇천 원~1만 원대 | 서울 리전, 고정 IP 무료, **브라우저에서 버튼 하나로 서버 접속** (프로그램 설치 불필요) |
| 오라클 클라우드 무료 서버 | 0원 (평생 무료 등급) | 고정 IP 무료, 서울/춘천 리전. 가입·접속 과정이 더 복잡하고 카드 등록 필요 |
| 국내/해외 VPS (카페24, 가비아, Vultr 서울 등) | 월 4천~1만원 | 가입이 쉽고 안정적 |
| 집/사무실 PC | 0원 | PC를 계속 켜둬야 하고, 인터넷 IP가 바뀌면 마켓에 다시 등록해야 함 |

## 1. 먼저 체험해보기 (내 PC, 5분)

1. [Node.js](https://nodejs.org) **22 LTS 이상** 설치
2. [코드 ZIP 내려받기](https://github.com/yongki6696/rsi-watch/archive/refs/heads/claude/wonderful-lamport-2cedpj.zip) → 압축을 풀고 안의 `orderhub` 폴더로 이동
   - 윈도우: `start-windows.bat` 더블클릭
   - 맥/리눅스: 터미널에서 아래 실행

```bash
npm install
```

```bash
npm start
```

3. 브라우저에서 `http://localhost:3000` 접속 → 비밀번호 설정
4. [스토어] → [스토어 연결] → **데모 스토어** 선택 → 가짜 주문으로 발주/송장/발송 흐름을 체험

## 2. 실제 운영 설치 (고정 IP 서버)

### 2-1. 서버 만들기 - 가장 쉬운 방법: AWS 라이트세일

컴퓨터는 이 과정에서 한 번만 쓰면 되고, 이후에는 휴대폰으로만 사용합니다.

1. [lightsail.aws.amazon.com](https://lightsail.aws.amazon.com) 에서 AWS 가입 후 **인스턴스 생성**
   - 위치: **서울 (ap-northeast-2)** / 플랫폼: **Linux/Unix** / 블루프린트: **OS 전용 → Ubuntu (22.04 또는 24.04 LTS)**
   - 요금제: 메모리 **1GB 이상** 권장 → 이름을 정하고 [인스턴스 생성]
2. 인스턴스 → **네트워킹** 탭
   - **고정 IP 생성** → 방금 만든 인스턴스에 연결 (이 IP를 마켓 API에 등록합니다. 연결된 고정 IP는 무료)
   - **IPv4 방화벽 → 규칙 추가 → HTTPS(443)** (HTTP 80은 기본으로 열려 있음)
3. 인스턴스 화면의 **[SSH를 사용하여 연결]** 버튼을 누르면 브라우저에 검은 터미널 창이 열립니다
   - 명령어 붙여넣기: 터미널 오른쪽 아래 **클립보드 아이콘**에 붙여넣은 뒤, 터미널 안에서 **마우스 오른쪽 클릭**
4. 아래 **2-2 도메인**을 만들고, **2-3 설치**의 두 줄을 이 터미널에 붙여넣으면 끝입니다

### 2-1(무료). 서버 만들기 - 오라클 클라우드 평생 무료 서버

브라우저만으로 끝납니다 (컴퓨터에 프로그램 설치 불필요). 메뉴 이름은 오라클 화면 개편에 따라 조금 다를 수 있습니다.

**① 가입** - [oracle.com/kr/cloud/free](https://www.oracle.com/kr/cloud/free/) → [무료로 시작하기]
- **홈 리전은 꼭 `South Korea Central (Seoul)` 또는 `South Korea North (Chuncheon)`** 으로 고르세요. 나중에 바꿀 수 없고, 무료 서버는 홈 리전에서만 만들 수 있습니다
- 본인 확인용으로 해외결제 되는 카드 등록이 필요합니다 (확인용 소액 승인 후 취소되며 요금은 나가지 않습니다)

**⭐ 가장 쉬운 방법: Cloud Shell 에 한 줄 붙여넣기 (②~⑤를 자동으로)**

가입 후 [duckdns.org](https://www.duckdns.org) 에서 주소 이름을 하나 만들고(화면 위쪽 **token** 도 복사), 오라클 콘솔 오른쪽 위 **모니터 모양 아이콘 → Cloud Shell** 을 열어 아래 한 줄을 붙여넣으세요.
```bash
bash <(curl -fsSL https://raw.githubusercontent.com/yongki6696/rsi-watch/refs/heads/claude/wonderful-lamport-2cedpj/orderhub/oracle-setup.sh)
```
주소 이름과 token 을 물어보면 입력하고 `Y` 를 누르면, 네트워크·포트·무료 서버·오더허브 설치·DuckDNS 연결까지 자동으로 하고, 접속 주소와 마켓에 등록할 서버 IP 를 알려줍니다 (10~20분). 서버 자리가 부족하다고 나오면 잠시 뒤 같은 한 줄을 다시 실행하면 됩니다.

아래 ②~⑤는 직접 하는 방법입니다.

**② 접속용 키 만들기 (Cloud Shell)** - 콘솔 오른쪽 위 **`>_` 아이콘(Cloud Shell)** 을 눌러 검은 창을 열고, 아래 두 줄을 차례로 붙여넣습니다
```bash
ssh-keygen -t rsa -b 4096 -N "" -f ~/.ssh/orderhub
```
```bash
cat ~/.ssh/orderhub.pub
```
- 화면에 나온 `ssh-rsa ...` 로 시작하는 한 줄 전체를 드래그해서 복사해둡니다

**③ 서버(인스턴스) 만들기** - 메뉴 → 컴퓨트 → 인스턴스 → **[인스턴스 생성]**
- 이미지: **Canonical Ubuntu 22.04** (Minimal 아닌 것)
- 구성(Shape): **VM.Standard.E2.1.Micro** (Always Free 표시가 있는 것. A1.Flex 도 무료지만 "용량 부족"이 자주 남)
- 네트워킹: 기본값 그대로 (새 가상 클라우드 네트워크 생성 + **공용 IPv4 주소 지정**)
- SSH 키: **공개 키 붙여넣기** 를 고르고 ②에서 복사한 한 줄을 붙여넣기 → [생성]
- 1~2분 뒤 상태가 "실행 중"이 되면 **공용 IP 주소**를 메모합니다 (이 IP를 마켓 API에 등록)

**④ 80·443 포트 열기** - 인스턴스 상세 → **서브넷** 링크 → **보안 목록(Default Security List)** → **수신 규칙 추가**
- 소스 CIDR `0.0.0.0/0`, IP 프로토콜 TCP, 대상 포트 `80` → [+ 다른 수신 규칙] 으로 `443` 도 같은 방식으로 추가

**⑤ 서버 접속** - 다시 Cloud Shell 에서 (IP 자리에 ③의 공용 IP)
```bash
ssh -i ~/.ssh/orderhub ubuntu@공용IP
```
- 처음 한 번 `yes` 를 입력합니다. 이제 이 검은 창에서 아래 **2-2 도메인**을 만든 뒤 **2-3 설치**의 두 줄을 붙여넣으면 됩니다

**검은 창(Cloud Shell·SSH) 없이 자동 설치하는 방법 (Cloud Shell 이 안 열릴 때 추천)**

서버를 만들 때 '초기화 스크립트'를 넣어두면, 서버가 처음 켜질 때 혼자 오더허브 설치까지 끝냅니다.
1. [duckdns.org](https://www.duckdns.org) 에서 도메인 이름을 먼저 만들어 둡니다 (IP 는 나중에 입력)
2. 인스턴스 생성 화면에서 이미지·구성은 위 ③과 같이 고르고, SSH 키는 **[키 쌍 자동 생성] → [전용 키 저장]** (비상용으로 보관)
3. **고급 옵션 표시(Show advanced options) → 관리(Management) → 초기화 스크립트 → cloud-init 스크립트 붙여넣기** 에 아래 내용을 붙여넣습니다. `myshop.duckdns.org` 는 **내 도메인으로 바꾸세요**
```bash
#!/bin/bash
cd /opt
git clone -b claude/wonderful-lamport-2cedpj https://github.com/yongki6696/rsi-watch.git
cd rsi-watch/orderhub
DOMAIN=myshop.duckdns.org bash install.sh > /var/log/orderhub-install.log 2>&1
```
4. [생성] 후 위 ④처럼 80·443 포트를 열고, 공용 IP 가 나오면 DuckDNS 에 그 IP 를 입력합니다
5. 10~15분 뒤 `https://내도메인` 으로 접속하면 끝입니다 (설치 기록은 서버의 `/var/log/orderhub-install.log`)

**⑥ (권장) 무료 서버가 회수되지 않게 하기** - 오라클은 무료 계정의 서버가 오래 한가하면(CPU 사용률이 아주 낮으면) 회수(정지)할 수 있습니다. 오더허브는 가볍게 동작해서 여기에 걸릴 수 있으니, 콘솔에서 계정을 **종량제(Pay As You Go)로 업그레이드**해두는 것을 권장합니다. 업그레이드해도 **Always Free 표시가 있는 것만 쓰면 요금은 0원**입니다. 회수되더라도 삭제가 아니라 정지라서, 콘솔에서 [시작]을 누르면 그대로 다시 돌아갑니다

### 2-2. 무료 도메인 만들기 (DuckDNS)

웹앱 푸시 알림과 보안 접속(HTTPS)에는 도메인이 필요합니다. 가지고 있는 도메인이 있으면 그걸 쓰셔도 됩니다.

1. [duckdns.org](https://www.duckdns.org) 에 구글 계정 등으로 로그인
2. 원하는 이름 입력(예: `myshop`) → **current ip** 칸에 서버 공인 IP 입력 → update
3. 도메인: `myshop.duckdns.org`

### 2-3. 설치 (서버에 SSH 접속 후)

```bash
git clone -b claude/wonderful-lamport-2cedpj https://github.com/yongki6696/rsi-watch.git
```

```bash
cd rsi-watch/orderhub && sudo bash install.sh
```

도메인을 물어보면 `myshop.duckdns.org` 처럼 입력합니다. 2~3분 뒤 `https://myshop.duckdns.org` 로 접속해 비밀번호를 정하면 끝입니다.
(Docker와 HTTPS 인증서(Let's Encrypt)를 스크립트가 자동으로 설치·발급합니다)

## 3. 마켓 API 연결

오더허브 [스토어] 화면 맨 위에 **"마켓 API에 등록할 서버 IP"** 가 표시됩니다. 아래 각 마켓 설정에 이 IP를 등록하세요.

### 네이버 스마트스토어 (커머스API)
1. [커머스API센터](https://apicenter.commerce.naver.com) 에 스마트스토어 판매자 계정으로 로그인
2. **애플리케이션 등록** (내 스토어 직접 사용)
3. API 권한에서 **주문** 관련 항목(주문 조회, 발주/발송 처리)과 **문의** 관련 항목(고객 문의, 상품 문의) 선택
   (문의 권한이 없어도 주문 수집은 정상 동작합니다)
4. **API 호출 IP** 에 서버 IP 등록
5. 발급된 **애플리케이션 ID / 시크릿**(`$2a$`로 시작)을 오더허브에 입력 → [연결 테스트]

### 쿠팡 (Wing Open API)
1. [쿠팡 Wing](https://wing.coupang.com) 로그인 → 우측 상단 판매자명 → **추가판매정보**
2. **OPEN API 키 발급** → 연동 방식 **자체개발(직접입력)** 선택
3. IP 주소 칸에 서버 IP 입력 (여러 개면 쉼표로 구분)
4. **업체코드(A로 시작) / Access Key / Secret Key** 를 오더허브에 입력 → [연결 테스트]
5. ⚠️ 쿠팡 OPEN API 키는 **약 180일마다 재발급**이 필요합니다. 만료되면 오더허브가 "수집 오류" 알림을 보냅니다 → [키 변경]에서 새 키 입력

### 11번가 (베타)
1. 11번가 셀러오피스 / [Open API 센터](https://openapi.11st.co.kr) 에서 **Open API Key** 발급 (서버 IP 등록 메뉴가 있으면 IP 등록)
2. 오더허브에 Key 입력 → [연결 테스트]
3. 11번가 연동은 베타입니다. 처음 며칠은 셀러오피스 화면과 수집 결과를 함께 확인해주세요.

### G마켓 · 옥션 (ESM Trading API, 베타)
G마켓과 옥션은 ESM PLUS의 같은 API를 씁니다. **오더허브에는 G마켓·옥션을 각각 스토어로 연결**합니다(같은 Secret Key 사용 가능).
1. [ESM API 센터](https://etapi.gmarket.com) → **API 시작하기**에서 이용 신청
   - 제출 항목: **ESM+ 마스터 ID**, 사용할 API(**주문·배송**), **호출 IP(서버 IP)**
   - 검토 후 **Secret Key**를 발급받습니다 (지마켓/옥션 판매자 회원이어야 합니다)
2. 오더허브 [스토어 연결] → G마켓(또는 옥션) → **마스터 ID / 판매자 ID / Secret Key** 입력 → [연결 테스트]
3. 참고
   - 마켓 정책상 주문조회는 **판매자 ID별 5초에 1번**만 가능해서, 오더허브가 자동으로 간격을 두고 조회합니다 (수집에 10~20초 걸릴 수 있음)
   - 결제완료 주문은 주문확인 → 발송처리 순서여야 해서, 송장을 바로 보내도 오더허브가 주문확인부터 자동 처리합니다
   - 고객이 결제완료 상태에서 취소하면 주문이 목록에서 사라집니다. 오더허브는 **두 번 연속 사라지면 "취소요청(확인 필요)" 알림**을 보내고, ESM PLUS에서 취소를 확인했다면 주문 상세의 **[취소된 주문으로 표시]**를 누르면 됩니다

### 롯데ON (OpenAPI, 베타)
1. 롯데ON 파트너(판매자)센터 → **판매자정보 → OpenAPI 관리 → [키 발급]**
2. 허용 IP에 서버 IP를 **CIDR 형식**으로 등록 (예: `1.2.3.4/32`)
3. 발급된 **인증키**를 오더허브에 입력 → [연결 테스트] (인증키 유효기간 1년)
4. 발주완료 시 롯데ON에 **상품준비**, 발송처리 시 **발송완료(택배사·송장)** 상태를 통보합니다
5. 베타 연동입니다. [연결 테스트] 결과의 **"응답 구조 보기"** 내용을 복사해 개발자에게 전달하면 필드를 더 정확히 맞출 수 있습니다

> 스토어를 처음 연결하면 최근 7일(설정 가능)의 주문을 **알림 없이** 가져오고, 그 다음부터 들어오는 주문만 알림을 보냅니다.

## 4. 휴대폰 알림 설정 ([알림] 화면)

여러 방법을 **동시에** 켤 수 있습니다. 추천 조합: **웹앱 푸시 + 텔레그램(또는 ntfy)**

### 📱 웹앱 푸시 (추천 · 앱 설치 불필요)
알림을 누르면 오더허브의 해당 주문 화면이 바로 열립니다.
- **안드로이드(크롬)**: 오더허브 접속 → 메뉴(⋮) → **홈 화면에 추가** → [알림] → **이 기기에서 알림 받기** → 허용
- **아이폰(iOS 16.4 이상)**: **Safari**로 접속 → 공유 버튼(□↑) → **홈 화면에 추가** → 홈 화면의 오더허브 앱 실행 → [알림] → **이 기기에서 알림 받기** → 허용
  - 아이폰은 반드시 홈 화면에 추가한 앱에서 눌러야 합니다 (Safari 탭에서는 불가)
- [테스트 알림]으로 확인하세요. 휴대폰을 바꾸거나 앱을 지웠다면 다시 등록하면 됩니다.

### ✈️ 텔레그램 (매우 안정적 · 무료)
1. 텔레그램에서 **@BotFather** 검색 → `/newbot` → 봇 이름 입력 → **토큰** 받기
2. 만든 봇을 검색해서 아무 메시지나 보내기 (예: "안녕")
3. 오더허브 [알림] → 토큰 붙여넣기 → **자동 찾기**(채팅 ID) → 저장 → 테스트 알림

### 🔔 ntfy (가입 없는 무료 알림 앱)
1. 휴대폰에 **ntfy** 앱 설치 (플레이스토어/앱스토어)
2. 오더허브 [알림] → 토픽 이름 **랜덤 생성** → 저장
3. ntfy 앱에서 [+] → 같은 토픽 이름으로 구독 → 테스트 알림
- 토픽 이름이 비밀번호 역할을 하므로 남이 추측하기 어려운 이름을 쓰세요 (알림에는 주문자 이름 등이 포함됩니다).

## 5. 매일 쓰는 방법

1. 📱 **"🛒 신규주문"** 알림 → 누르면 주문 상세가 열림
2. **[발주정보 전체복사]** → 공급처(도매꾹·오너클랜 등) 주문서에 붙여넣어 발주
3. 오더허브에서 **[발주완료 처리]** (공급처·매입가 기록은 선택) → 마켓에도 발주확인 처리됨
4. 공급처에서 송장번호가 나오면 [발주완료] 탭에서 **택배사 + 송장번호 입력 → [발송]**
5. 마켓에 송장이 등록되고 주문이 **발송완료**로 이동 → 이후 배송완료/구매확정도 자동 반영
6. 📱 **"💬 고객문의"** 알림이 오면 [문의] 화면에서 내용을 보고 바로 답변 (스마트스토어)

여러 건은 체크박스로 선택해서 한 번에 [발주완료]/[송장 전송]할 수 있고,
송장이 많으면 목록 화면 우측 ☰ 버튼 → **송장 일괄등록**에 엑셀 내용을 붙여넣으세요:

```
주문번호            택배사       송장번호
2026112290000001    CJ대한통운   510012345678
2026112290000002    한진택배     410012345678
```
(2열 `주문번호 · 송장번호` 형식이면 기본 택배사를 사용합니다. 오더허브에서 받은 CSV의 주문번호/상품주문번호를 그대로 쓰면 됩니다)

## 6. 관리

- **업데이트**: `git pull && docker compose up -d --build` (데이터는 그대로 유지)

- **수집 주기·자동 발주확인·기본 택배사**: [설정] 화면

## 7. 문제 해결

| 증상 | 해결 |
| --- | --- |
| "등록되지 않은 IP" / IP_NOT_ALLOWED | 마켓 API 설정의 IP와 [스토어] 화면의 서버 IP가 같은지 확인 |
| 스마트스토어 "인증 실패" | 애플리케이션 ID/시크릿을 다시 복사. 서버 시간이 5분 이상 틀려도 실패합니다 (`timedatectl`로 확인) |
| 쿠팡 "인증 실패" | 업체코드·키 확인, 키 만료(180일) 여부 확인 |
| 웹앱 푸시가 안 옴 | https 주소로 접속했는지, 아이폰은 홈 화면 앱에서 등록했는지, 휴대폰 설정에서 알림이 허용됐는지 확인. 텔레그램/ntfy를 함께 켜두면 안전합니다 |
| 접속이 안 됨 | 오라클 보안 목록 80/443 수신 허용, DuckDNS IP가 서버 IP와 같은지 확인 |
| 마켓 셀러센터에서 직접 처리한 주문 | 다음 수집 때 마켓 상태(발송/취소 등)가 자동 반영됩니다 |
| G마켓·옥션 "5초당 1회" 오류 | 다른 프로그램(다른 주문관리 솔루션)이 같은 판매자 ID로 동시에 주문조회를 하고 있을 수 있습니다. 다음 수집 때 자동 재시도됩니다 |
| 베타 마켓에서 주문 정보 일부가 비어 보임 | [스토어] → [연결 테스트] → "응답 구조 보기"를 복사해서 알려주세요 |

## 8. 개발자용

- Node.js 22.13+ (내장 `node:sqlite` 사용), 의존성은 `bcryptjs`, `web-push` 두 개뿐
- 테스트: `npm test` — 실제 API 방식대로 서명을 검증하는 가짜 마켓 서버(네이버·쿠팡·11번가·텔레그램·ntfy)로 수집→알림→발주→송장→발송 전체 흐름을 검증합니다
- 구조: `src/connectors/*` (마켓별 API), `src/sync.js` (스케줄러·알림), `src/orders.js` (주문 병합·상태), `src/actions.js` (발주·송장·발송), `public/` (PWA 화면)
- 환경변수: `.env.example` 참고. `DISABLE_SCHEDULER=true` 로 자동 수집 끄기
