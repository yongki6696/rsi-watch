2. 알림 키 만들기 (VAPID)

푸시 알림을 보내려면 한 쌍의 키가 필요해요. 아래 버튼을 누르면 이 화면 안에서 새로 만들어요. 한 번 정해서 넣은 뒤에는 바꾸지 마세요 (바꾸면 모든 사람이 알림을 다시 켜야 해요).

VAPID_PUBLIC_KEY
VAPID_PRIVATE_KEY (비밀)
ADMIN_TOKEN (비밀)

3. Cloudflare 에 넣기

  1. Cloudflare 대시보드 → Workers & Pages → price-radar → Settings → Variables and Secrets
  2. Add → Type 은 Secret 으로, 아래 이름과 값을 하나씩 넣고 Deploy 
    COUPANG_ACCESS_KEY   (쿠팡 파트너스 Access Key)
COUPANG_SECRET_KEY   (쿠팡 파트너스 Secret Key)
VAPID_PUBLIC_KEY     (위에서 만든 값)
VAPID_PRIVATE_KEY    (위에서 만든 값)
VAPID_SUBJECT        mailto:내이메일@example.com
ADMIN_TOKEN          (위에서 만든 값)
  3. 쿠팡 키를 넣기 전에는 데모 모드(가상 가격)로 동작해요. 키를 넣으면 데모 데이터는 자동으로 지워져요.

4. 운영 현황 보기

ADMIN_TOKEN 을 넣으면 사용자 수, 쿠팡 API 사용량, 마지막 확인 결과를 볼 수 있어요.
