# 매매 규칙 정리: 차슐랭 채널 분석 방식 → 코드

## 이 문서의 출처와 한계

- 대상 채널: **「차슐랭ㅣ비트코인 분석」** (`@차슐랭-p5f`, 소개 문구 "차트로 수익을 먹는 남자", 2025-09 개설)
- 이 봇을 만든 환경에서는 YouTube 접속이 막혀 있었습니다. 그래서 **영상이나 자막을 직접 보지 못했습니다.**
- 아래 규칙은 검색으로 확인한 영상 제목·설명에 반복해서 나오는 분석 요소를 일반적인 기술적 분석 규칙으로 옮긴 **추정**입니다.
  - 영상 제목 예: 「비트코인 마지막 함정」, 「비트코인 그들이 만든 위험한 프레임」, 「비트코인의 방향과 알트장의 진실」
  - 설명에 나오는 요소: 핵심 가격대, 지지·저항 구간, 매물대, 유동성 구간, 단기·중기 방향, 주요 변곡점
- 채널이 실제로 쓰는 지표, 진입 타점, 손절 위치는 아직 확인하지 못했습니다. 아래 표의 "확인 필요" 칸이 그 부분입니다.

## 개념 → 규칙 대응표

| 채널에서 쓰는 개념 | 봇 규칙 | 코드 위치 / 설정 | 확인 필요 |
|---|---|---|---|
| 단기·중기 방향 | 상위 봉(기본 일봉) EMA50·EMA200과 종가 위치로 상승/하락/중립 판단. 상승이면 롱만, 하락이면 숏만 (strict) | `strategy.compute_bias`, `bias_timeframe`, `bias_mode` | 채널이 방향을 판단할 때 쓰는 지표(이평선? 추세선? 구조?) |
| 핵심 가격대 / 지지·저항 | 스윙 고점·저점(좌우 5봉)이 2번 이상 반응한 가격을 ATR 폭으로 묶어 '구간'으로 만듦 | `levels.find_zones`, `pivot_window`, `min_touches`, `zone_width_atr` | 가격대를 몇 봉, 몇 번 터치 기준으로 긋는지 |
| 매물대 | 최근 300봉 볼륨 프로파일에서 거래량이 몰린 봉우리(HVN, POC)를 가격대 후보로 추가 | `indicators.volume_nodes`, `vp_bins`, `hvn_quantile` | 매물대를 어떤 기간으로 보는지 |
| 유동성 구간 / 함정 / 프레임 | **셋업 A (스윕)**: 지지 구간 아래를 꼬리로 찌른 뒤(0.1~1.5 ATR) 다시 구간 위에서, 봉의 위쪽 절반으로 마감하고 거래량이 평균의 1.2배 이상 → 다음 봉 롱. 저항 위 스윕은 숏 | `strategy._sweep_signals`, `sweep_*`, `volume_mult` | 함정을 판단하는 기준(꼬리 길이, 거래량, 확인 봉) |
| 저항 → 지지 전환 | **셋업 B (리테스트)**: 저항을 돌파 마감한 뒤 12봉 안에 처음 되돌아와 구간 위에서 마감 → 롱 (숏은 반대) | `strategy._retest_signals`, `retest_window` | 리테스트 진입을 실제로 쓰는지 |
| 목표가 | 진입 방향의 다음 '핵심' 가격대(강도 3 이상). 없으면 2R | `_plan`, `target_min_strength`, `fallback_rr` | 분할 익절 여부, 목표가 기준 |
| 틀리면 인정 (손절) | 손절은 꼬리 또는 구간 바깥 + 0.2 ATR. 손익비가 1.5 미만이면 진입하지 않음. +1R이면 손절을 본절로 이동 | `stop_buffer_atr`, `min_rr`, `breakeven_at_r` | 손절 위치 기준 |
| 자금 관리 | 1회 손실은 자산의 1%, 하루 -3% 또는 3연패면 그날 신규 진입 중지, 레버리지 최대 3배 | `risk.py`, `risk:` 섹션 | 채널이 권하는 비중·레버리지 |

## 실데이터 검증 결과 (요약)

Bitstamp BTC/USD 실제 시세(2019-01 ~ 2026-10)로 백테스트했습니다. 수수료 편도 0.05%, 슬리피지 0.02%를 반영했습니다. 자세한 수치는 [README](README.md#실데이터-백테스트-결과)에 있습니다.

- 위 규칙만으로는 **통계적으로 의미 있는 우위(edge)를 찾지 못했습니다.**
- 1시간봉은 수수료를 빼기 전에도 거래당 평균 약 -0.05R이었고, 수수료 반영 후에는 -0.18R이었습니다.
- 기본값(4시간봉 + 일봉 추세 필터)은 7년 동안 약 -3%로 거의 본전이었습니다. 같은 기간 단순 보유는 +2,167%였습니다.

따라서 **채널의 실제 규칙을 반영하기 전까지는 실거래를 권하지 않습니다.**

## 채널의 실제 규칙을 반영하는 방법

1. 주요 영상(특히 매매법이나 원칙을 설명하는 영상)에서 자막을 복사합니다. 방법: YouTube 영상 → 설명란 "더보기" → **"스크립트 표시"** → 전체 선택 → 복사
2. `autotrader/transcripts/영상제목.txt` 로 저장하거나 대화창에 붙여 넣습니다.
3. 반복해서 나오는 진입·손절·익절 조건을 위 표의 "확인 필요" 칸에 채우고, 규칙을 코드로 옮깁니다.
4. 같은 데이터로 다시 백테스트합니다. 이때 **기간을 나눠서** 검증합니다. 예를 들어 2019~2023년에서 규칙을 정하고 2024년 이후 데이터로 확인합니다.
