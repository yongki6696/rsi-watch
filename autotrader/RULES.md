# 매매 규칙: 차슐랭 채널 자막 → 코드

## 출처

채널 **「차슐랭ㅣ비트코인 분석」**의 2025년 9~10월 영상 6개 자막(9/15, 9/28, 10/7, 10/11, 10/16, 10/20)에서 정리했습니다. 영상마다 같은 방법이 반복됩니다. 바로 **유동성(손절 물량) 훼손 → 내부 구조 전환 확인 → 진입 → 부분 익절 → 본절**입니다. 스마트 머니 콘셉트(SMC)라고 부르는 방식입니다.

## 채널의 매매 원칙 (자막 인용)

| 원칙 | 자막 근거 |
|---|---|
| 방향을 맞히는 것보다 확률 높은 자리에서 리스크를 제한하고 거래한다 | "방향을 맞추는 것과 실제로 트레이딩을 통해 돈을 버는 것은 다른 개념" (10/20 0:18), "확률을 확보할 수 있는 특정 구간에서 리스크를 제한하고 거래" (10/20 5:44) |
| 한쪽 방향을 고집하지 않고 롱·숏을 모두 한다 | "상승장이 시작됐다라는 관점을 유지를 하고 있음에도 불구하고 숏 포지션으로 트레이딩할 자리가 나오면 숏 포지션으로 트레이딩을 합니다" (10/11 4:18) |
| 스윙 고점 뒤 = 바이사이드 유동성(숏 손절 물량), 스윙 저점 뒤 = 셀사이드 유동성(롱 손절 물량) | (10/20 1:31, 4:37), (10/7 4:35) |
| 1시간봉 단기 고점·저점 = 내부 유동성, 더 큰 구조의 고점·저점 = 외부 유동성 | "내부 유동성들은 한시간봉에서 체크" (10/20 3:49), "외부 셀사이드 유동성 … 10월 15일 79.7K 저점" (10/20 4:22). 외부를 4h 스윙으로 둔 것은 해석 |
| 유동성을 훼손한 뒤 **핀바**로 안쪽 마감하거나 **내부 구조가 반대로 전환**되면 진입 | "윗꼬리를 말아내리고 핀바 형태로 바로 캔들이 안으로 회기를 한다면 … 신규 매도 포지션을 구축할 수 있는" (10/20 4:06), "저점을 훼손했을 때 내부 구조의 상승 전환 혹은 밑꼬리를 크게 말아올리는 핀바" (10/20 4:54) |
| 손절은 훼손한 고점·저점 너머 | "이 저점 이탈를 손절로 잡고 롱 포지션을 열어" (10/16 1:09), "해당 고점을 손절로 잡고 숏 포지션 진입" (9/28 1:22) |
| 하락(상승) 발산 중에는 바닥(천장)을 미리 예상하지 않는다. 구조 전환을 기다린다 | "하락 발산이 나올 때는 저점을 미리 예상하지 않는 게 중요" (10/16 3:23), "유동성을 수입한 이 캔들 전체를 확실하게 상방으로 돌려내야만 롱 포지션의 확률이 높아지기 때문에" (9/28 2:18) |
| 오더블록: 구조를 깬 **임펄스** 캔들 직전의 반대 캔들 = 서플라이/디맨드 존. 터치 후 내부 구조가 전환되면 진입 | "이 임펄스 바로 직전에 여기 이 매도 오더블록이 … 서플라이존에 해당" (10/11 3:13), "서플라이 존 터치를 하게 된다면 이제 여기서의 내부 구조가 하락으로 전환이 되는지 체크를 해서 이제 숏 포지션 진입이 가능한" (10/16 3:55) |
| 가격 구조: 고점·저점이 낮아지면 하락 구조. **기준 가격**(마지막 다리의 출발점)을 종가로 넘으면 구조 전환 | "84.3k를 … 확실하게 상방 돌파 한 채로 마감이 되면 … 하락 구조가 마무리되고" (10/20 3:23), "83.1k의 … 저점을 최종적으로 훼손할 필요가 있어요" (10/7 4:03) |
| 레인지 안에서 위아래로 털 때는 쉬고, 상·하단 기준 가격이 훼손될 때부터 매매 | "이 안에서 움직임을 보여주는 동안에는 트레이딩을 잠시 멈추시는게 좋아요" (9/15 3:57) |
| 부분 익절 후 남은 물량은 본절 손절을 걸고 보유 | "부분 익절 후에 자녀(잔여) 물량 보유" (10/20 2:21), "자녀(잔여) 물량은 본절로서(본절 로스)를 걸고" (10/7 0:26), "스탑로스가 터치가 되더라도 리스크가 제로인 상황" (10/7 3:23). 괄호는 자동 자막 오타 보정 |
| 핵심은 분석보다 리스크 관리 | "실제 트레이딩의 핵심은 이런 차트 분석의 원리보다는 리스크를 조절하는 기술에 달려 있다" (10/11 4:59) |

## 코드로 옮긴 방식

| 원칙 | 코드 | 설정 |
|---|---|---|
| 내부 유동성 | 1h 스윙 고점·저점 (좌우 5봉). 확정된 뒤 처음 넘어서는 봉이 '훼손' | `liq_pivot_window`, `liquidity_timeframe` |
| 외부 유동성 / 구조 | 4h 스윙 고점·저점 (좌우 3봉). 구조 상태와 기준 가격 | `ext_pivot_window`, `smc.structure` |
| 핀바 트리거 | 훼손이 일어난 1h 봉의 반대쪽 꼬리가 봉 길이의 50% 이상이고, 레벨 안쪽에서 마감 | `enable_pinbar`, `pinbar_wick` |
| 내부 구조 전환 트리거 | 훼손 뒤 3시간(15m × 12봉) 안에, 훼손 극점 이전의 마지막 15m 스윙(좌우 2봉)을 종가로 반대로 깸 (처음 깨는 봉에서만) | `enable_choch`, `entry_pivot_window`, `arm_bars` |
| 발산 중 진입 금지 | 레벨을 1h ATR × 1.5보다 더 뚫으면 함정이 아니라 돌파로 보고 진입하지 않음 | `sweep_max_atr` |
| 오더블록 | 4h 몸통 ≥ ATR × 1.5 이고 직전 스윙을 처음 종가로 깬 캔들 = 임펄스. 그 직전 3봉 안의 마지막 반대 색 캔들 고가~저가 = 존. 30일 안의 첫 터치 뒤 구조 전환 시 진입 | `enable_ob`, `ob_impulse_atr`, `ob_max_age` |
| 손절 | 훼손 극점 + 1h ATR × 0.1 | `stop_buffer_atr` |
| 부분 익절 → 본절 | 1.5R에서 50%를 지정가로 익절하고 손절을 진입가로 이동. 나머지는 1h 스윙을 따라 손절을 옮김(`trail`) 또는 본절 유지(`hold`) | `tp1_r`, `tp1_fraction`, `runner` |
| 양방향 | 4h 구조와 상관없이 롱·숏 모두 (`"off"`). 구조 방향으로만 하려면 `structure` | `bias_mode` |
| 리스크 관리 | 1회 손실 = 자산의 1%, 하루 -3% 또는 3연패 시 중지 | `risk:` |

## 코드로 옮기지 못한 것

- **어떤 훼손을 고를지에 대한 재량.** 채널은 여러 유동성 중 "지금 의미 있는 자리"를 골라 진입하지만, 봇은 조건이 맞는 자리에서 모두 진입합니다.
- **10분봉.** 바이낸스 API에는 10분봉이 없어서 15분봉으로 대신했습니다.
- **익절 위치.** 자막에는 "부분 익절"만 나오고 언제 하는지 기준이 없어서 1.5R로 정했습니다.
- **포지션 크기·레버리지.** 채널은 수억 원 규모로 매매하지만 비중 기준은 말하지 않습니다. 봇은 1회 1% 리스크입니다.
- **레인지 안 매매 중지(9/15).** 봉 안에서 위아래로 터는 구간을 별도로 걸러 내지 않습니다. 다만 레벨 훼손이 있어야만 진입하므로 일부는 자연히 걸러집니다.
