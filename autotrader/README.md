# BTC 자동매매 봇 — 추세추종 자동매매 + 차슐랭 채널 신호 알림

기본 모드(`mode: hybrid`)는 두 가지를 함께 돌립니다.

| | 하는 일 | 주문 |
|---|---|---|
| **추세추종** | 일봉 종가가 직전 20일 최고가를 넘으면 롱, 직전 10일 최저가 아래로 마감하면 청산 | ✅ 자동 주문 |
| **채널 방식 신호** | 「차슐랭ㅣ비트코인 분석」 자막에서 정리한 매매법(유동성 훼손 → 구조 전환)을 15분봉마다 확인해, 신호와 근거를 텔레그램으로 알림 | ❌ 알림만. 판단은 직접 |

이렇게 나눈 이유는 실데이터 검증 결과입니다.

- 채널 방식을 그대로 자동매매하면 수수료 때문에 수익이 나지 않았습니다([결과](#채널-방식-백테스트-결과)).
- 단순 추세추종은 2014~2026년 세 구간 모두 수익이었습니다([결과](#추세추종-백테스트-결과)).

채널 방식 자동매매도 `mode: smc`로 계속 쓸 수 있습니다. 규칙과 자막 근거는 [RULES.md](RULES.md)에 있습니다.

> ⚠️ **먼저 읽어 주세요**
> - 과거 수익이 미래 수익을 보장하지 않습니다. 추세추종은 **최대 낙폭이 -35%~-53%**였습니다. 이 정도 하락을 견딜 수 있는 금액만 넣으세요.
> - 기본값은 **모의매매**와 **테스트넷**입니다. 실거래는 충분히 확인한 뒤 본인 책임으로만 하세요.
> - 이 프로그램은 투자 권유가 아닙니다.

## 빠른 시작 (하이퍼리퀴드, 하이브리드)

```bash
cd autotrader
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m pytest -q                         # 59개 테스트
cp config.example.yaml config.yaml          # 하이퍼리퀴드 + hybrid + 테스트넷이 기본

# 1) 텔레그램 알림 (선택이지만 권장)
export TELEGRAM_BOT_TOKEN=...  TELEGRAM_CHAT_ID=...

# 2) 모의매매: 실제 시세로 돌리고 주문은 가상. 키 불필요
python -m bot run -c config.yaml

# 3) 테스트넷 실주문: config.yaml 에 live.enabled: true (exchange.sandbox: true 유지)
export HYPERLIQUID_WALLET_ADDRESS=0x...     # 메인 지갑 주소
export HYPERLIQUID_PRIVATE_KEY=0x...        # API 지갑 개인키 (출금 권한 없음)
python -m bot run -c config.yaml --live

# 4) 메인넷: 테스트넷에서 진입·비상 손절·청산이 제대로 되는 걸 본 뒤 exchange.sandbox: false
```

- 봇은 24시간 켜진 PC나 클라우드 서버에서 돌려야 합니다.
- 추세추종 판단은 하루 한 번, 일봉 마감(UTC 00:00 = 한국 오전 9시) 직후에 합니다.
- 채널 신호 확인은 15분마다 합니다.
- **봇 전용 지갑(계정)을 따로 쓰세요.** 시작할 때 거래소에 봇이 모르는 BTC 포지션이 있으면 실행을 거부합니다.

### 추세추종 동작

```
매일 일봉 마감 직후 (UTC 00:00)
 - 현금 상태: 종가 > 직전 20일 최고가 → 시장가 롱, 명목가치 = 자산 x 1배
              + 거래소에 비상 손절(10일 최저가 - ATR x 2) 스탑 주문
 - 롱 상태:   종가 < 직전 10일 최저가 → 시장가 청산
              아니면 비상 손절을 위로만 이동 (새로 계산한 값이 더 높을 때만)
 - 봇이 꺼진 사이 폭락하면 거래소의 비상 손절이 실행됨
 - 청산 주문이 실패하면 다음 확인(30초 뒤)에 다시 시도
```

## 추세추종 백테스트 결과

- **데이터**: Bitstamp BTC/USD 일봉, 2014~2026
- **비용**: 하이퍼리퀴드 기준. 시장가 0.045%, 슬리피지 0.02%, **롱 보유 중 펀딩비 연 11%**
- **조건**: 롱만, 명목가치 = 자산 x 1배

| 기간 | 추세추종 수익 | 최대 낙폭 | 그냥 보유 | 보유 최대 낙폭 | 거래 수 |
|---|---|---|---|---|---|
| 2014–2018 | **+815%** (연 56%) | -48% | +389% | -83% | 20 |
| 2019–2022 | **+530%** (연 58%) | -53% | +332% | -77% | 17 |
| 2023–2026 | **+101%** (연 20%) | -35% | +406% | -53% | 22 |

- 세 구간 모두 수익이었고, 그냥 보유하는 것보다 낙폭이 작았습니다.
- 2023–26년처럼 꾸준히 오르는 장에서는 그냥 보유보다 덜 벌었습니다. 장점은 2014·2018·2022년 같은 폭락장을 피한 것입니다.
- 펀딩비가 수익을 꽤 깎습니다. 펀딩비가 없다면 2023–26년은 +146%입니다. 상승장에서는 펀딩비가 연 11%보다 높을 수 있습니다.
- 숏도 하게 하면 2023–26년이 -11%로 나빠져서 롱만 합니다(`trend.allow_short: false`).
- 승률은 46% 정도입니다. 작은 손실이 여러 번 나고 큰 추세에서 크게 버는 구조라, **연속 손실 구간을 견디는 게 핵심**입니다.

직접 확인하려면 하이퍼리퀴드 대신 과거가 긴 바이낸스 데이터를 받아서 돌리면 됩니다.

### 바이낸스 연결 순서

1. **연습용 키 발급**: [바이낸스 선물 테스트넷](https://testnet.binancefuture.com)에서 API 키를 발급하고 `config.yaml`을 `sandbox: true`로 둡니다. 바이낸스 데모 트레이딩 계정을 쓰려면 `sandbox: false`, `demo: true`로 둡니다.
2. **실계정 키 발급** (충분히 검증한 뒤): 바이낸스 → API 관리
   - **선물 거래(Enable Futures)만 켜기**
   - **출금 권한 끄기**
   - **IP 제한**을 봇이 도는 서버 IP로 설정
3. **선물 계정 설정**
   - 포지션 모드: **단방향(One-way)**. 헤지 모드에서는 봇의 reduceOnly 주문이 거부됩니다.
   - 마진: 격리(Isolated) 권장
   - 선물 지갑에 USDT 입금
   - 잔고가 너무 적으면 최소 주문 금액 때문에 진입하지 않습니다. 1차 익절(절반) 주문도 최소 기준을 넘어야 하므로, 테스트넷에서 실제로 진입되는 금액을 먼저 확인하세요.
4. **키 넣기**: 환경변수로 넣습니다. 파일에 키를 쓰지 마세요.
   ```bash
   export EXCHANGE_API_KEY=...
   export EXCHANGE_API_SECRET=...
   ```

### 하이퍼리퀴드 연결 순서

1. **연습**: `exchange.sandbox: true`로 두면 하이퍼리퀴드 테스트넷에 연결됩니다. 테스트넷 USDC는 하이퍼리퀴드 테스트넷 faucet에서 받습니다. 메인넷 입금 이력이 있는 지갑이어야 할 수 있습니다.
2. **API 지갑 만들기**: 하이퍼리퀴드 웹사이트 → More → **API**에서 API 지갑(에이전트)을 만들고 메인 지갑으로 승인합니다.
   - **API 지갑은 주문만 할 수 있고 출금은 못 합니다.** 메인 지갑 개인키는 절대 봇에 넣지 마세요.
   - API 지갑에는 유효기간이 있을 수 있으니 만료일을 확인하세요.
3. **입금**: 메인 지갑에서 USDC를 하이퍼리퀴드로 입금합니다(Arbitrum 브리지). 최소 주문 금액은 10 USDC입니다.
4. **키 넣기**:
   ```bash
   export HYPERLIQUID_WALLET_ADDRESS=0x...   # 메인 지갑 주소 (API 지갑 주소가 아님)
   export HYPERLIQUID_PRIVATE_KEY=0x...      # API 지갑 개인키
   ```
5. **config.yaml 설정**: `symbol: BTC/USDC:USDC`, `exchange: {id: hyperliquid, market_type: future, sandbox: true}`, `live.history_bars: 5000`
6. **ccxt 기본 동작 두 가지를 껐습니다**
   - ccxt는 기본값으로 하이퍼리퀴드 주문마다 0.01%의 '빌더 수수료'를 ccxt 주소로 보냅니다. 봇은 0%로 설정합니다.
   - ccxt는 첫 주문 때 계정에 ccxt 추천인 코드를 영구 등록합니다. 봇은 등록하지 않습니다.

## 명령어

```bash
python -m bot demo                                   # 합성 데이터로 동작 확인 (수익률 의미 없음)
python -m bot fetch -c config.yaml --since 2019-01-01 [--exchange binance --symbol BTC/USDT --timeframe 1d]
python -m bot backtest -c config.yaml [--strategy trend|smc] [--csv 파일] [--start 2023-01-01]
python -m bot run -c config.yaml                     # 모의매매 (실시세 + 가상 주문)
python -m bot run -c config.yaml --live              # 실거래 (live.enabled: true 도 필요)
python -m bot run -c config.yaml --once              # 한 번만 판단하고 종료 (cron용)
```

- `backtest`는 `mode: hybrid`면 추세추종(일봉), `mode: smc`면 채널 방식(15분봉)을 검증합니다. `--strategy`로 바꿀 수 있습니다.
- 텔레그램 알림: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`를 설정하면 진입·청산·비상 손절·오류와 채널 신호를 보냅니다.

### 안전장치

- 실거래는 `live.enabled: true`와 `--live`가 **둘 다** 있어야 동작합니다.
- hybrid 모드에서 실제 주문을 내는 건 추세추종뿐입니다. 채널 신호는 알림만 보냅니다.
- 진입 직후 손절 주문이 실패하면 즉시 시장가로 청산합니다.
- 손절을 옮길 때는 새 손절 주문을 먼저 걸고 나서 기존 주문을 취소합니다.
- 시작할 때 거래소에 봇이 모르는 포지션이 있으면 실행을 거부합니다.
- 마감된 지 반 봉 이상 지난 신호는 무시합니다. 진입 직전 현재가가 이미 손절가나 1차 목표를 지나쳤으면 진입하지 않습니다.
- 최소 주문 수량에 못 미치면 주문하지 않습니다. 설정 키에 오타가 있으면 바로 오류가 납니다.

- **비용**: 바이낸스 선물 기준. 시장가 0.05%, 지정가 익절 0.02%, 슬리피지 0.02%
- **보수적 가정**: 같은 봉에서 손절과 익절이 모두 닿으면 손절로 처리합니다.

| 4h 구조 방향으로만, 30m 진입 | **+0.09** (337) | **-0.06** (306) |
| 외부(4h) 유동성만 | -0.15 (298) | -0.17 (332) |
| 오더블록만 | -0.53 (10) | +0.81 (7) |

- 2019–22년에 플러스였던 "4h 구조 방향" 조합들은 2023–26년에 **모두 마이너스로 바뀌었습니다.** 과거에 맞춘 결과일 뿐 우위가 아닙니다.
- "hold"의 큰 수익은 각 기간 **딱 1건**에서 나왔습니다(1,422일·1,095일 동안 들고 있던 롱). 사실상 단순 보유와 같고, 그 1건을 빼면 거래당 -0.6R / -0.5R입니다.
- 오더블록은 7년 동안 17건뿐이라 판단할 수 없습니다.

**수익성 개선 시도**

미리 정한 후보 4개를 2019–22년과 2023–26년 두 기간에 돌려 봤습니다. 숫자는 **최종 자산 기준 수익률**입니다. 거래당 평균 R은 레버리지 상한에 걸린 소수 거래가 부풀릴 수 있어서 쓰지 않았습니다.

| 변형 (하이퍼리퀴드 수수료) | 2019–22 | 2023–26 |
|---|---|---|
| 기본 (시장가 진입, 1h 트레일) | -12.9% | -20.5% |
| **지정가 진입** (신호 봉 종가, 4봉 대기) | +19.6% | **+0.8%** |
| 남은 물량 4h 스윙 트레일 | +69.8% | -21.9% |
| 지정가 진입 + 4h 트레일 | +106.8% | -4.1% |

- 지정가 진입(메이커 수수료, 슬리피지 없음)만 두 기간 모두 개선됐지만, 그래도 **본전 수준**입니다. 바이낸스 수수료로는 +12.4% / -7.0%입니다.
- 4h 트레일은 2019–22년 추세장에서만 좋았고 2023–26년에는 마이너스였습니다.
- 지정가 진입은 아직 **백테스트 전용**입니다(`strategy.entry_mode: limit`). 실시간 실행은 이 설정을 거부합니다.

**비교용: 단순 추세추종** (채널 방식 아님, 일봉, 현물 롱만, 수수료+슬리피지 0.07%, 교과서 기본값)

| 규칙 | 2019–22 수익 / MDD | 2023–26 수익 / MDD |
|---|---|---|
| 종가가 200일 평균 위일 때만 보유 | +56% / -64% | +254% / -32% |
| 50일 평균 > 200일 평균일 때 보유 | +101% / -63% | +98% / -40% |
| 20일 신고가 돌파 시 매수, 10일 신저가 이탈 시 매도 | +649% / -52% | +147% / -34% |
| (참고) 그냥 보유 | +332% / -77% | +405% / -53% |

- 이 단순한 규칙들은 두 기간 모두 수익이었고, 낙폭은 보유보다 작았습니다.
- 하지만 2023–26년 같은 상승장에서는 그냥 보유보다 덜 벌었습니다. 장점은 폭락을 피하는 것입니다.

**정리**

- 자막의 규칙은 수수료를 빼기 전에는 거래당 +0.13R의 작은 우위가 있었습니다.
- 하지만 15분봉 손절폭(약 0.6~1%)에서는 수수료가 그만큼을 가져갑니다.
- 채널의 실제 수익은 규칙만이 아니라 **어떤 자리를 고르는지에 대한 재량**에서 나오는 것으로 보이고, 봇은 그 재량을 따라 하지 못합니다.
- **모의매매로 신호를 관찰하고 직접 판단하는 보조 도구**로 쓰기를 권합니다.

## 폴더 구조

```
autotrader/
├─ bot/
│  ├─ config.py      설정 (dataclass 기본값 + YAML, 오타 검출)
│  ├─ indicators.py  ATR, 스윙 피벗
│  ├─ smc.py         유동성 레벨·훼손, 4h 가격 구조·기준 가격, 오더블록 (미래 참조 없음)
│  ├─ strategy.py    채널 방식: 핀바 / 내부 구조 전환 트리거, 손절·익절 계산, 트레일링
│  ├─ trend.py       추세추종: 20일 돌파 / 10일 이탈, 비상 손절, 펀딩비 반영 백테스트
│  ├─ trade.py       포지션, 부분 익절 → 본절, 체결 순서 판정 (백테스트·실거래 공용)
│  ├─ risk.py        수량 계산, 일일 손실 한도, 연속 손실 휴식
│  ├─ backtest.py    봉 단위 백테스트와 통계
│  ├─ broker.py      PaperBroker(모의) / CcxtBroker(실거래: 스탑·지정가 익절 주문)
│  ├─ live.py        실시간: TrendTrader(자동매매) / SignalAlerter(알림) / LiveTrader(smc 자동매매)
│  └─ __main__.py    명령줄 (demo / fetch / backtest / run)
├─ tests/            시나리오, 미래 참조 없음, 추세추종·알림, 주문 흐름(하이퍼리퀴드 실제 ccxt 코드 포함) 테스트
├─ config.example.yaml
└─ RULES.md          자막 → 규칙 대응표
```

## 한계

- **거래소 주문 연동은 실제 거래소에서 검증하지 못했습니다.** `CcxtBroker`는 가짜 거래소 객체로 주문 순서만 테스트했습니다(개발 환경에서 거래소 API 접속이 막혀 있었음). 바이낸스 선물의 스탑 주문이 algo 주문으로 처리되는 점(조회·취소 시 `trigger` 파라미터)은 ccxt 4.5 소스를 보고 반영했습니다. **반드시 테스트넷에서 먼저 확인하세요.**
- 펀딩비는 추세추종 백테스트에만 연 11% 고정값으로 넣었습니다. 실제 펀딩비는 시장 상황에 따라 바뀝니다. 채널 방식 백테스트와 모의매매에는 펀딩비가 없습니다.
- **하이퍼리퀴드**
  - 시장가와 손절 주문은 '최대 5% 불리한 가격까지 허용하는 지정가'로 나갑니다(ccxt 기본값). 급락으로 순간 5% 넘게 밀리면 손절이 일부만 체결될 수 있습니다.
  - 실제 ccxt 하이퍼리퀴드 코드로 주문 생성과 서명까지는 테스트로 확인했지만, 실제 API로 전송해 보지는 못했습니다(개발 환경에서 접속이 막혀 있었음).
  - 백테스트 데이터는 Bitstamp BTC/USD라서 하이퍼리퀴드 BTC 무기한 가격과 약간 다릅니다.
- 채널 신호는 실시간에서 최근 5,000봉(15분봉 약 52일)만으로 유동성을 계산하므로, 그보다 오래된 레벨은 백테스트와 다르게 빠질 수 있습니다.
