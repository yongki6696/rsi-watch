# BTC 자동매매 봇 — 차슐랭 채널 방식 (유동성 훼손 → 구조 전환 → 부분 익절)

비트코인 분석 채널 **「차슐랭ㅣ비트코인 분석」** 영상 자막 6개에서 정리한 매매법을 그대로 코드로 옮겼습니다. 규칙과 자막 근거는 [RULES.md](RULES.md)에 있습니다.

같은 코드로 다음 세 가지를 실행합니다.

- **백테스트**: 과거 데이터로 검증
- **모의매매**: 실시간 시세에 가상 주문
- **실거래**: ccxt로 거래소에 실제 주문

> ⚠️ **먼저 읽어 주세요**
> - 실제 시세(2019~2026) 백테스트에서 **수수료를 내고 나면 수익이 나지 않았습니다.** [결과](#실데이터-백테스트-결과)를 꼭 확인하세요.
> - 기본값은 **모의매매**입니다. 실거래는 테스트넷에서 충분히 검증한 뒤 본인 책임으로만 하세요.
> - 이 프로그램은 투자 권유가 아닙니다.

## 동작 방식

```
15분봉이 마감될 때마다
 ① 무장: 1h 단기 고점(바이사이드)/저점(셀사이드) 또는 4h 고점·저점을 처음 넘는 '훼손',
         또는 4h 오더블록(임펄스 직전 반대 캔들) 터치
 ② 트리거 (훼손 후 3시간 안에)
    - 핀바: 훼손한 1h 봉이 긴 꼬리를 남기고 레벨 안쪽으로 마감
    - 구조 전환: 15m 직전 스윙을 반대로 깨고 마감
    - 1h ATR x 1.5 넘게 뚫리면 함정이 아니라 돌파 → 진입 안 함
 ③ 진입: 다음 봉 시장가 / 손절: 훼손 꼬리 끝 너머 (거래소에 스탑 주문)
 ④ 관리: 1.5R 에서 절반 지정가 익절 → 손절을 본절로 → 나머지는 1h 스윙 따라 손절 이동
 ⑤ 자금: 1회 손실 1%, 하루 -3% 또는 3연패면 그날 중지, 최대 3배
```

## 거래소: 바이낸스 선물 또는 하이퍼리퀴드

| | **바이낸스 USDⓈ-M 선물** | **하이퍼리퀴드 무기한** | 업비트 현물 |
|---|---|---|---|
| 숏 | ✅ 가능 | ✅ 가능 | ❌ 불가 (채널 매매의 절반이 숏) |
| 손절 주문 | ✅ 거래소에 걸어 둠. 봇이나 PC가 꺼져도 손절이 실행됨 | ✅ 거래소에 걸어 둠 (체결 가격은 트리거 가격에서 최대 5%까지 허용) | ❌ API로 스탑 주문을 걸 수 없어 봇이 가격을 보고 직접 청산. 봇이 꺼지면 손절이 안 됨 |
| 연습 환경 | ✅ 테스트넷 / 데모 트레이딩 (가짜 돈) | ✅ 테스트넷 | ❌ 없음 |
| 수수료 (기본 등급) | 시장가 0.05%, 지정가 0.02% (BNB로 내면 10% 할인) | 시장가 0.045%, 지정가 0.015% | 0.05% |
| 계정·인증 | 거래소 계정 + API 키 | 지갑(탈중앙화 거래소). 메인 지갑 주소 + API 지갑 개인키 | 거래소 계정 + API 키 |
| 과거 데이터 | 수년치 | 최근 5,000봉까지만 (15분봉 약 52일) → 백테스트는 바이낸스 데이터로 | 수년치 |
| 봇 설정 | `id: binance`, `market_type: future` | `id: hyperliquid`, `market_type: future`, `symbol: BTC/USDC:USDC` | `id: upbit`, `market_type: spot` |

- 채널 운영자는 OKX도 씁니다(자막의 "오케"). `id: okx`로 연결할 수 있지만 바이낸스로만 검증했습니다.
- **"앱"이 아니라 프로그램입니다.** 봇은 24시간 켜진 PC나 클라우드 서버(VPS)에서 돌아가야 합니다. 휴대폰에서는 거래소 앱으로 확인하고, 텔레그램 알림을 받습니다.
- 해외 거래소 이용에 따른 세금·신고 의무는 본인이 확인하세요.

### 바이낸스 연결 순서

1. **연습용 키 발급**: [바이낸스 선물 테스트넷](https://testnet.binancefuture.com)에서 API 키를 발급하고 `config.yaml`을 `sandbox: true`로 둡니다. 바이낸스 데모 트레이딩 계정을 쓰려면 `sandbox: false`, `demo: true`로 둡니다.
2. **실계정 키 발급** (충분히 검증한 뒤): 바이낸스 → API 관리
   - **선물 거래(Enable Futures)만 켜기**
   - **출금 권한 끄기**
   - **IP 제한**을 봇이 도는 서버 IP로 설정
3. **선물 계정 설정**
   - 포지션 모드: **단방향(One-way)**. 헤지 모드에서는 봇의 reduceOnly 주문이 거부됩니다.
   - 마진: 격리(Isolated) 권장
   - 선물 지갑에 USDT 입금
   - 잔고가 너무 적으면 최소 주문 금액 때문에 진입하지 않습니다. 1차 익절(절반) 주문도 최소 기준을 넘어야 하므로, 테스트넷에서 실제로 진입되는 금액을 먼저 확인하세요.
4. **키 넣기**: 환경변수로 넣습니다. 파일에 키를 쓰지 마세요.
   ```bash
   export EXCHANGE_API_KEY=...
   export EXCHANGE_API_SECRET=...
   ```

### 하이퍼리퀴드 연결 순서

1. **연습**: `exchange.sandbox: true`로 두면 하이퍼리퀴드 테스트넷에 연결됩니다. 테스트넷 USDC는 하이퍼리퀴드 테스트넷 faucet에서 받습니다. 메인넷 입금 이력이 있는 지갑이어야 할 수 있습니다.
2. **API 지갑 만들기**: 하이퍼리퀴드 웹사이트 → More → **API**에서 API 지갑(에이전트)을 만들고 메인 지갑으로 승인합니다.
   - **API 지갑은 주문만 할 수 있고 출금은 못 합니다.** 메인 지갑 개인키는 절대 봇에 넣지 마세요.
   - API 지갑에는 유효기간이 있을 수 있으니 만료일을 확인하세요.
3. **입금**: 메인 지갑에서 USDC를 하이퍼리퀴드로 입금합니다(Arbitrum 브리지). 최소 주문 금액은 10 USDC입니다.
4. **키 넣기**:
   ```bash
   export HYPERLIQUID_WALLET_ADDRESS=0x...   # 메인 지갑 주소 (API 지갑 주소가 아님)
   export HYPERLIQUID_PRIVATE_KEY=0x...      # API 지갑 개인키
   ```
5. **config.yaml 설정**: `symbol: BTC/USDC:USDC`, `exchange: {id: hyperliquid, market_type: future, sandbox: true}`, `live.history_bars: 5000`
6. **ccxt 기본 동작 두 가지를 껐습니다**
   - ccxt는 기본값으로 하이퍼리퀴드 주문마다 0.01%의 '빌더 수수료'를 ccxt 주소로 보냅니다. 봇은 0%로 설정합니다.
   - ccxt는 첫 주문 때 계정에 ccxt 추천인 코드를 영구 등록합니다. 봇은 등록하지 않습니다.

## 설치와 사용법

```bash
cd autotrader
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m pytest -q                       # 43개 테스트
python -m bot demo                        # 합성 데이터로 동작 확인 (수익률 의미 없음)

cp config.example.yaml config.yaml        # 설정 복사 후 수정
python -m bot fetch -c config.yaml --since 2023-01-01        # 15분봉 받기 (키 불필요)
python -m bot backtest -c config.yaml                         # → results/trades.csv, equity.csv
python -m bot backtest -c config.yaml --start 2025-01-01      # 기간 지정
python -m bot run -c config.yaml                              # 모의매매 (실시세 + 가상 주문)
python -m bot run -c config.yaml --live                       # 실거래 (live.enabled: true 도 필요)
```

- 텔레그램 알림: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` 환경변수를 설정하면 진입·1차 익절·손절 이동·청산·오류를 보내 줍니다. 알림에는 진입 근거도 함께 옵니다. 예: "내부 바이사이드 유동성 83,100 훼손 → 유동성 봉 윗꼬리 핀바로 안쪽 마감 | 4h 구조 하락"
- `--once`: 한 번만 판단하고 종료합니다(cron용).

### 안전장치

- 실거래는 `live.enabled: true`와 `--live`가 **둘 다** 있어야 동작합니다.
- 진입 직후 손절 주문이 실패하면 즉시 시장가로 청산합니다.
- 손절을 옮길 때는 새 손절 주문을 먼저 걸고 나서 기존 주문을 취소합니다.
- 시작할 때 거래소에 봇이 모르는 포지션이 있으면 실행을 거부합니다.
- 마감된 지 반 봉 이상 지난 신호는 무시합니다. 진입 직전 현재가가 이미 손절가나 1차 목표를 지나쳤으면 진입하지 않습니다.
- 최소 주문 수량에 못 미치면 주문하지 않습니다. 설정 키에 오타가 있으면 바로 오류가 납니다.

## 실데이터 백테스트 결과

- **데이터**: Bitstamp BTC/USD 1분봉([ff137/bitstamp-btcusd-minute-data](https://github.com/ff137/bitstamp-btcusd-minute-data))을 15m/30m로 묶음
- **비용**: 바이낸스 선물 기준. 시장가 0.05%, 지정가 익절 0.02%, 슬리피지 0.02%
- **보수적 가정**: 같은 봉에서 손절과 익절이 모두 닿으면 손절로 처리합니다.

**기본 설정, 2019-01 ~ 2026-10**

| 항목 | 값 |
|---|---|
| 거래 수 | 1,249 (롱 633 / 숏 616; 핀바 785, 구조 전환 454, 오더블록 10) |
| 승률 / 1차 익절 도달 | 42.0% / 42.1% |
| Profit Factor | 0.94 |
| 거래당 평균 | **-0.02R** (수수료 빼기 전 **+0.13R**) |
| 총 수익률 | **-39.4%** (같은 기간 단순 보유 +2,158%) |
| 최대 낙폭 | -45.2% |

**규칙 변형 비교**: 2019~2022년에서 고르고 2023~2026년으로 확인했습니다. 수치는 거래당 R, 괄호는 거래 수입니다.

| 변형 | 2019–22 | 2023–26 |
|---|---|---|

| 최소 손절폭 0.3 ATR (손절이 더 타이트) | -0.02 (700) | -0.09 (693) |

| 4h 구조 방향으로만, 30m 진입 | **+0.09** (337) | **-0.06** (306) |
| 외부(4h) 유동성만 | -0.15 (298) | -0.17 (332) |
| 오더블록만 | -0.53 (10) | +0.81 (7) |
| 1차 익절 1R / 2.5R | -0.06 / -0.09 | -0.10 / -0.17 |
| 남은 물량 본절 유지(hold) | +15.9 (22) | +1.10 (61) |

- 2019–22년에 플러스였던 "4h 구조 방향" 조합들은 2023–26년에 **모두 마이너스로 바뀌었습니다.** 과거에 맞춘 결과일 뿐 우위가 아닙니다.
- "hold"의 큰 수익은 각 기간 **딱 1건**에서 나왔습니다(1,422일·1,095일 동안 들고 있던 롱). 사실상 단순 보유와 같고, 그 1건을 빼면 거래당 -0.6R / -0.5R입니다.
- 오더블록은 7년 동안 17건뿐이라 판단할 수 없습니다.

**수수료 민감도** (기본 설정)

| 수수료 | 2019–22 | 2023–26 |
|---|---|---|
| 바이낸스 기본 | -0.02R, -18.0% | -0.03R, -26.6% |
| BNB 할인 (0.045% / 0.018%, 슬리피지 0.01%) | +0.00R, -5.2% | +0.01R, -7.1% |
| 하이퍼리퀴드 기본 등급 (0.045% / 0.015%) | -0.01R, -12.9% | -0.02R, -20.5% |
| 업비트 현물 (롱만, 0.05%) | -0.06R, -25.3% | +0.03R, +0.1% |

**정리**

- 자막의 규칙은 수수료를 빼기 전에는 거래당 +0.13R의 작은 우위가 있었습니다.
- 하지만 15분봉 손절폭(약 0.6~1%)에서는 수수료가 그만큼을 가져갑니다.
- 채널의 실제 수익은 규칙만이 아니라 **어떤 자리를 고르는지에 대한 재량**에서 나오는 것으로 보이고, 봇은 그 재량을 따라 하지 못합니다.
- **모의매매로 신호를 관찰하고 직접 판단하는 보조 도구**로 쓰기를 권합니다.

```

│  ├─ config.py      설정 (dataclass 기본값 + YAML, 오타 검출)

│  └─ __main__.py    명령줄 (demo / fetch / backtest / run)
├─ tests/            시나리오(핀바·구조 전환·돌파 무효), 미래 참조 없음, 주문 흐름 테스트
├─ config.example.yaml
└─ RULES.md          자막 → 규칙 대응표
```

## 한계

- **거래소 주문 연동은 실제 거래소에서 검증하지 못했습니다.** `CcxtBroker`는 가짜 거래소 객체로 주문 순서만 테스트했습니다(개발 환경에서 거래소 API 접속이 막혀 있었음). 바이낸스 선물의 스탑 주문이 algo 주문으로 처리되는 점(조회·취소 시 `trigger` 파라미터)은 ccxt 4.5 소스를 보고 반영했습니다. **반드시 테스트넷에서 먼저 확인하세요.**
- 펀딩비는 반영하지 않았습니다.
- **하이퍼리퀴드**
  - 시장가와 손절 주문은 '최대 5% 불리한 가격까지 허용하는 지정가'로 나갑니다(ccxt 기본값). 급락으로 순간 5% 넘게 밀리면 손절이 일부만 체결될 수 있습니다.
  - 실제 ccxt 하이퍼리퀴드 코드로 주문 생성과 서명까지는 테스트로 확인했지만, 실제 API로 전송해 보지는 못했습니다(개발 환경에서 접속이 막혀 있었음).
  - 백테스트 데이터는 Bitstamp BTC/USD라서 하이퍼리퀴드 BTC 무기한 가격과 약간 다릅니다.
- 실시간에서는 최근 약 62일치(`history_bars`)만으로 유동성을 계산하므로, 그보다 오래된 레벨은 백테스트와 다르게 빠질 수 있습니다.
