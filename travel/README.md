# ✈️ 어디가지 — 나라별 최저가 항공권 + 가격 하락 알림

왕복 날짜만 넣으면 **가장 싼 나라부터** 항공권을 쭉 보여주고,
즐겨찾기한 항공편이 **최저가를 새로 찍으면** 알림을 보내주는 웹앱(PWA)입니다.

- 나라별로 항공권 **5개씩**, 출발 시간대(새벽·오전·오후·저녁)를 **골고루 섞어서** 보여줘요
- ☆ 를 눌러 즐겨찾기 → 가격 추이 그래프, 담은 가격 대비 등락, 목표가 설정
- 가격이 내려가면 휴대폰/PC 알림

## 바로 써보기

GitHub Pages가 켜져 있다면 `https://<아이디>.github.io/rsi-watch/travel/` 로 들어가면 됩니다.
처음에는 **데모 데이터(가상 가격)** 로 동작하니 바로 눌러볼 수 있어요.
설정 탭의 **가격 하락 시뮬레이션**으로 알림이 어떻게 오는지도 확인할 수 있어요.

내 컴퓨터에서 열어보려면 저장소 폴더에서:

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000/travel/` 을 엽니다.

휴대폰에서는 **홈 화면에 추가**해서 앱처럼 쓰세요. (iPhone은 홈 화면에 추가해야 알림이 와요.)

## 어떻게 고르나요?

1. 출발지·날짜로 모든 목적지 항공권을 가져옵니다.
2. 나라별로 묶고, 그 나라 **최저가 순서**로 나라를 정렬합니다.
3. 나라마다 5개를 고를 때, 가장 싼 항공편은 무조건 넣고
   나머지는 *이미 고른 시간대와 겹치면 가격에 12% 벌점*을 줘서 고릅니다.
   → 많이 비싸지 않다면 다른 시간대 항공편이 들어가서 시간대가 자연스럽게 섞여요.

## 알림 규칙

- 즐겨찾기한 뒤 **최저가를 새로 찍으면** 알림 (설정의 "이만큼 내려가면 알림" 이상 내려갔을 때)
  - 예) 30만 → 28만(알림) → 32만 → 29만(알림 없음, 28만보다 비쌈) → 27.5만(알림)
- **목표가**를 정해두면 그 가격 이하로 처음 내려왔을 때 한 번 더 알려줘요.

알림이 오는 방법은 세 가지입니다.

| 방법 | 언제 확인하나요 | 준비물 |
|---|---|---|
| 앱이 열려 있을 때 | 설정한 주기(기본 30분)마다 + 앱을 열 때마다 | 없음 |
| 크롬 + 홈 화면 설치 | 브라우저가 적당한 때 (최소 3시간 간격, 보장은 안 됨) | 안드로이드/PC 크롬 |
| **서버 + ntfy (추천)** | 3시간마다, 앱이 꺼져 있어도 | 아래 서버 설정 + ntfy 앱 |

## 실제 가격 연결하기 (선택)

데모 데이터 대신 실제 가격을 보려면 [Travelpayouts](https://www.travelpayouts.com) (Aviasales) 무료 API와,
API 키를 숨겨주는 작은 서버(Cloudflare Workers, 무료)를 씁니다.

### 1) Travelpayouts API 토큰 받기

1. travelpayouts.com 가입 (무료 제휴 프로그램)
2. 대시보드의 개발자(API) 메뉴에서 **API 토큰** 복사
3. (선택) **Marker(제휴 마커)** 번호 — `wrangler.toml` 의 `[vars]` 에 `TP_MARKER = "번호"` 로 넣으면 예약 링크에 붙어요

### 2) 서버 배포 (Cloudflare Workers)

[Cloudflare](https://dash.cloudflare.com/sign-up) 무료 계정을 만든 뒤, 이 폴더에서:

```bash
cd travel/worker
```

```bash
npx wrangler login
```

```bash
npx wrangler secret put TP_TOKEN
```

(토큰을 붙여넣으라고 나오면 1번에서 복사한 토큰을 붙여넣기)

```bash
npx wrangler deploy
```

배포가 끝나면 `https://eodigaji.<내계정>.workers.dev` 같은 주소가 나와요.

### 3) 앱에 연결

앱 → **설정 → 가격 데이터 → 실제 가격** 선택 → 서버 주소 붙여넣기 → **연결 테스트**.
"연결됨 ✓" 이 뜨면 끝입니다.

## 앱이 꺼져 있을 때도 알림 받기 (선택)

서버가 3시간마다 즐겨찾기 가격을 확인하고 [ntfy](https://ntfy.sh) 로 휴대폰에 푸시를 보냅니다.
ntfy는 무료 푸시 알림 앱이에요 (iPhone/안드로이드).

1. 저장 공간(KV) 만들기:

   ```bash
   npx wrangler kv namespace create WATCH
   ```

2. 출력된 `id` 를 `travel/worker/wrangler.toml` 의 `[[kv_namespaces]]` 부분 주석을 풀고 넣기.
   `APP_URL` 도 본인 앱 주소로 바꾸기.
3. 다시 배포:

   ```bash
   npx wrangler deploy
   ```

4. 휴대폰에 **ntfy** 앱 설치 → **+ 구독** → 앱 설정 화면에 있는 **ntfy 토픽** 이름 입력
   (토픽 이름을 아는 사람은 누구나 그 알림을 볼 수 있으니 추측하기 어려운 이름을 쓰세요. 기본값이 무작위예요.)
5. 앱 → 설정 → **서버에 즐겨찾기 등록** → **테스트 푸시** 로 확인

한 번 등록하면 이후 즐겨찾기·목표가를 바꿀 때 자동으로 서버에 반영돼요.
서버에서 감시하는 건 **실제 가격**으로 담은 항공편만입니다 (데모 항공편은 제외).

## 꼭 알아두세요

- **데모 데이터는 가짜 가격**이에요. 노선·항공사는 그럴듯하게 만들었지만 실제 운항 스케줄이 아닙니다.
- Travelpayouts 가격은 사람들이 최근에 검색한 결과를 모아둔 **캐시 가격**이라 실제 예약 화면 가격과
  다를 수 있고, 인기가 적은 날짜·노선은 결과가 적거나 없을 수 있어요. 예약 전에 꼭 예약 사이트에서 확인하세요.
- 이 서버 코드는 가짜 응답으로 테스트했고, 실제 Travelpayouts·ntfy 서버에는 아직 연결해 보지 않았어요.
  연결 테스트에서 오류가 나면 오류 메시지를 확인해 주세요.
- Cloudflare 무료 요금제는 한 번 실행할 때 외부 요청 수 제한(약 50개)이 있어서 서버 감시는 30개까지로 막아뒀어요.

## 파일 구조

```
travel/
  index.html    화면 + 스타일
  app.js        화면 동작
  core.js       데모 가격 생성, 실제 가격 변환, 나라별 묶기/시간대 섞기, 알림 판단
  data.js       출발지·도시·항공사·국가 데이터
  store.js      즐겨찾기 저장 (IndexedDB)
  sw.js         서비스워커 (오프라인, 백그라운드 확인, 알림 클릭)
  worker/       Cloudflare Worker (API 키 숨김 프록시 + 3시간마다 감시 + ntfy 푸시)
  test/         자동 테스트
```

## 테스트

```bash
cd travel && npm test
```
